## Critical

### `robots.txt` returns 500

- **Issue:** Crawlers cannot read the crawl rules or the sitemap pointer. Next.js reports a conflict between `public/robots.txt` and `src/app/robots.ts`.
- **Evidence:** `GET http://localhost:3000/robots.txt` returned 500 with `A conflicting public file and page file was found for path /robots.txt`. `public/robots.txt` allows `/` and names the sitemap. `src/app/robots.ts` does the same.
- **Verification:** Verified from curl and source.
- **Fix:** Keep one of the two files. Delete the other.
- **Confirm:** `GET /robots.txt` returns 200, `User-agent: *`, `Allow: /`, and `Sitemap: https://astrologyforlove.com/sitemap.xml`.

## High

### Soulmate title promises a two-chart synastry reading

- **Issue:** The indexable title and meta description describe synastry between two people. The page calculates one natal chart.
- **Evidence:** Title from curl: `Soulmate Synastry Calculator — Romantic Destiny | AstrologyForLove`. Description starts `Explore deep synastry indicators…`. Visible `<h1>` and shell copy are `Soulmate Calculator`, and the form is a single `BirthDetailsForm` (`src/app/[locale]/soulmate-calculator/page.tsx`).
- **Verification:** Verified from curl and source.
- **Fix:** Rewrite the title and description to a one-person romantic profile (Venus, Moon, Mars). Point two-person soulmate intent at synastry or the moon-phase page.
- **Confirm:** The `<title>` and meta description no longer say synastry, and they match the single-chart form.

## Medium

### Homepage Open Graph image is missing

- **Issue:** Tool pages emit `og:image`. The homepage does not, so shares of the root URL have no branded image.
- **Evidence:** Curl of `/` has `og:title` and `og:url` and no `og:image`. Curl of `/love-compatibility` has `og:image` `https://astrologyforlove.com/opengraph-image`. `GET /opengraph-image` returned 200 (131,535 bytes). Homepage `twitter.card` in `src/app/[locale]/page.tsx` is `summary`, not `summary_large_image`.
- **Verification:** Verified from curl and source.
- **Fix:** Add the existing open-graph image to the homepage metadata and set the Twitter card to `summary_large_image`.
- **Confirm:** View source of `/` contains `og:image` pointing at `/opengraph-image`.

### Unpublished locales are noindex only via a response header

- **Issue:** `/es` and `/es/compatibilidad-amorosa` serve English copy with `lang="es"`. They do not include a robots meta tag. `X-Robots-Tag: noindex, follow` is set in `src/middleware.ts` for any locale that is not published.
- **Evidence:** Curl of `/es/love-compatibility` followed to `/es/compatibilidad-amorosa`. Canonical `https://astrologyforlove.com/love-compatibility`. hreflang only `en` and `x-default`. Header `noindex, follow`. No `name="robots"` meta. English `/love-compatibility` has no noindex header.
- **Verification:** Verified from curl and source.
- **Fix:** Also set `robots: { index: false, follow: true }` in HTML for draft locales, and keep `lang` aligned with the language of the body until a translation exists.
- **Confirm:** View source of `/es/compatibilidad-amorosa` contains `noindex`.

## Low

- **Issue:** First Load JS was not measured. A production build was not run because it shares `.next` with the dev server on port 3000.
- **Evidence:** No `npm run build` in this session.
- **Verification:** Not performed.
- **Fix:** Run `npm run build` when the dev server is stopped and flag any route above 150 kB First Load JS.
- **Confirm:** Build output lists route sizes.

### Sign-pair URLs are not published

- **Issue:** High-intent queries such as “Aries and Leo compatibility” have no dedicated URL. Live tools cover the calculators. `seo/keyword-clusters.json` does not exist, so volumes were not re-checked.
- **Evidence:** No sign-pair routes under `src/app/[locale]/`. Sitemap has 23 English URLs and no `/en` prefix.
- **Verification:** Verified from source and sitemap curl. Volumes in `seo/competitor-gaps.md` were not re-measured.
- **Fix:** Add sign-pair pages only with real copy, after this audit’s critical and high items.
- **Confirm:** A sample pair URL is in the sitemap and has a unique title.

## What passed

- Sampled English canonicals match the production host. Brand appears once in the title template.
- `/en` and `/en/love-compatibility` return 307 to the unprefixed URL. A trailing slash on `/love-compatibility/` returns 308 to the unprefixed path.
- One `<h1>` on every fetched page. Viewport is `width=device-width, initial-scale=1`. English pages use `lang="en"`.
- hreflang is only `en` and `x-default`.
- Tool JSON-LD is one script: `BreadcrumbList` plus `WebApplication`. No `FAQPage`, `AggregateRating`, or `Review`. Breadcrumb names match the visible trail on `/love-compatibility`.
- Marriage copy states tropical Western and links to Vedic kundli matching. Kundli title states Lahiri sidereal.
- Homepage, nav, and footer link the live money pages, including the relationship forecast.
- Cormorant Garamond and DM Sans load through `next/font` at weights 400, 500, and 600. No content `<img>` lacks alt. Focus uses `--color-focus-ring`.
- Robots source allows all user agents, including AI crawlers. That policy is not what the server returns today.
